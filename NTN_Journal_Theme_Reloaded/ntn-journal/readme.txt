Tema parent per testate di videogiochi, con estetica brutalista ispirata a Nothing OS.

== Description ==

NTN Journal è il tema parent dell'ecosistema NTN Journal: modelli di pagina (home, articoli, recensioni, catalogo giochi, Hub), stili Tailwind CSS v4, caratteri Inter e JetBrains Mono serviti dal sito, ricerca istantanea, modalità chiara e scura.

Il tema mostra i dati e il plugin NTN Journal Core li gestisce: il sito si vede anche senza il plugin, ma la maggior parte delle funzioni lo richiede.

== Installation ==

1. Installa e attiva prima il plugin NTN Journal Core.
2. Carica lo ZIP del tema parent da Aspetto > Temi.
3. Attiva il tema child "NTN Journal Reloaded" (consigliato) oppure il solo parent.
