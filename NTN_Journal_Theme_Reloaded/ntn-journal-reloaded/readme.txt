Tema child di NTN Journal: qui vanno solo le personalizzazioni del sito.

== Description ==

Tema child del tema parent NTN Journal. Dalla 4.10.0 è quasi vuoto di proposito: il sito funziona anche con il solo parent. Aggiungi qui le tue personalizzazioni (stili, piccoli ganci) per poter aggiornare il parent senza perderle.

Richiede il tema parent "NTN Journal" installato.

== Installation ==

1. Installa il tema parent NTN Journal.
2. Carica lo ZIP di questo tema da Aspetto > Temi e attivalo.
